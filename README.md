# MusicVerse 🎵

### Telugu Artist & Music Discovery Platform

MusicVerse is a responsive web application built to explore Telugu/Tollywood artists, discover songs, save favorite artists, and find upcoming live music events.

## Live Demo

https://naga-poojitha.github.io/MusicVerse/

## Features

- 🎤 Telugu/Tollywood artist discovery
- 🔎 Search artists, songs, and movies
- ❤️ Favorite artists
- 🎵 Music discovery with Spotify integration
- 🎧 Open songs directly in Spotify
- 📅 Upcoming Telugu music events
- 🔗 Event details linked to official booking pages
- 📱 Responsive design for desktop, tablet, and mobile
- 🍔 Responsive mobile navigation

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Lucide React
- Spotify links
